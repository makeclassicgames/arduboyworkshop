# Introducción

Bienvenido al taller de Arduboy. En esta sección encontrarás información sobre el dispositivo Arduboy, su historia y cómo se utiliza para crear juegos.

## ¿Qué es Arduboy?

Arduboy es un dispositivo de juego portátil basado en Arduino, diseñado para permitir a los usuarios crear y jugar sus propios videojuegos. Con una pantalla OLED, botones de control y un diseño compacto, Arduboy ofrece una experiencia de juego retro y educativa.

En este taller, aprenderás a programar juegos para Arduboy utilizando el lenguaje de programación C++ (usando el superset de Arduino) y la plataforma Arduino IDE. A lo largo del taller, se proporcionarán ejemplos y ejercicios prácticos para ayudarte a desarrollar tus habilidades de programación y diseño de juegos.

### Especificaciones Técnicas

Veamos algunas de las especificaciones técnicas del dispositivo Arduboy:

- **Pantalla:** OLED de 1.3 pulgadas con resolución de 128x64 píxeles.
- **Procesador:** ATmega32u4 a 8 MHz.
- **Memoria:** 32 KB de memoria flash, 2.5 KB de SRAM, 1 KB de EEPROM y además de 16MB de memoria externa para almacenamiento de juegos.
- **Batería:** Batería recargable de 180 mAh.
- **Conectividad:** Puerto USB para cargar y programar el dispositivo.

## Plataforma Arduboy

La plataforma Arduboy es un conjunto de librerías y herramientas que facilitan el desarrollo de juegos para el dispositivo. Incluye funciones para manejar gráficos, sonido y entrada de usuario, lo que permite a los desarrolladores centrarse en la lógica del juego y la creatividad.

Durante este taller, aprenderás a utilizar la plataforma Arduboy para crear tus propios juegos, desde conceptos básicos hasta técnicas más avanzadas. Se proporcionarán ejemplos de código y recursos adicionales para ayudarte a comprender cómo funciona la plataforma y cómo puedes aprovecharla al máximo.
