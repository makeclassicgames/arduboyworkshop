# Taller de Arduboy

En la presente página encontrarás información sobre el taller de Arduboy, un dispositivo de juego portátil basado en Arduino. Este taller está diseñado para enseñar a los participantes cómo programar y crear sus propios juegos utilizando la plataforma Arduboy.

## Materiales y Requisitos

Para este taller, los participantes necesitarán los siguientes materiales:

- Una computadora con conexión a internet.
- Un Arduboy (puede ser prestado durante el taller) con cable USB.
- Software de desarrollo Arduino IDE instalado en la computadora.

Se requieren algunos conocimientos básicos de programación y electrónica, aunque no es necesario ser un experto para participar.

!!! note
    El presente taller está dirigido a principiantes y entusiastas de la programación y los videojuegos. No es necesario tener experiencia previa en Arduino o desarrollo de juegos.
